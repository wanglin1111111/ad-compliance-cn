# 审查检查清单（Review Checklist）：逐项判据与行业专项

> 用途：第 3 步执行检查时逐项对照。每项结论三态：**有风险**（进风险清单）/ **无风险**（已查）/ **N/A**（必须写原因）。
> 纪律：静默跳过 = 视同未查，报告不成立。

执行记录里的 item id（validate.py D3 强制，必须一字不差）：

| item id | 对应本文件章节 |
|---|---|
| `absolute_claims` | 1. 绝对化用语 |
| `efficacy_claims` | 2. 功效宣称 |
| `data_claims` | 3. 数据宣称 |
| `comparative_claims` | 4. 对比宣称 |
| `inducement_promises` | 5. 诱导与承诺 |

每项 status ∈ `risk`/`clear`/`na`；`na` 必须写 `na_reason`；缺 item = D3 FAIL。

## 一、通用 5 项（所有渠道必跑）

### 1. 绝对化用语（依据 FL-001）

```
判据：出现 最/第一/国家级/最高级/最佳/顶级/极致/绝无仅有/万能 等词
  且用于商品/服务/品牌的效果或地位宣称
例外（不构成违规，标 N/A 或无风险并写原因）：
  [ ] 内部排名自指（"我司内部销量第一"——需核实是否属实，不属实=虚假宣传另论）
  [ ] 时间限定自指（"2025 年销量第一"——需有出处，否则进数据宣称项）
  [ ] 非宣称语境（"想要最好的效果，请坚持使用"——语气副词，个案判断，
     出 advice 级 + 建议替换为可验证表述）
  [ ] 描述客观属性且可验证（"行业唯一获 X 认证"——有证书=N/A，无证书=有风险）
易漏点：谐音/变体（"臻第一""NO.1""TOP1"）与图片内文字（详情页图里的极限词同样算）
```

### 2. 功效宣称（依据 FL-002/007/008，按行业取）

```
判据：内容对效果作出超出产品实际属性的描述
  化妆品：出现医疗词汇（"消炎""抗敏""修复受损屏障"需功效评价依据，
  "祛斑美白"属特殊功效需注册证——无依据=有风险）
  普通食品：出现保健功能暗示（"增强免疫""改善睡眠"=有风险，
  食品不得声称保健功能）
  非医疗产品：出现疾病治疗功能（"降血压""抗癌""治愈"=有风险/hard）
边界判断（出 risk 级 + 判断依据，不直接判死）：
  "调理""养护""改善"类模糊词：是否构成功效宣称 = 个案（看上下文是否指向
  疾病/医疗功能）→ 列 risk 项，写清"判断依赖：产品资质与宣称的具体指向"
```

### 3. 数据宣称（依据 FL-003）

```
判据：出现数字（百分比/倍数/人数/排名/销量）且用于支持效果或地位
  要求：有出处（报告名/调研机构/时间段）或明确标注"内部测试/样本量"
  无出处且无标注 = 有风险（risk 级；若数字明显夸大 = hard 候选 + human_review）
  "99% 用户推荐"（无出处）/ "销量第一"（无时间限定与出处）= 典型
  标注了"内部测试"但未写样本量/时间 = advice 级（补全标注）
易漏点：口播/视频字幕里的数字；"据统计"这种无主语的引语（=无出处）
```

### 4. 对比宣称（依据 FL-004）

```
判据：点名（或可识别的暗示）其他经营者 + 贬损性表述
  "比 XX 好用多了"（无依据）= 有风险
  "XX 家产品会卡顿，我们不会"（贬损+无依据）= 有风险
  可验证的客观对比（"接口数量 4 vs 2，来自官方参数表"）= N/A（写原因）
  不点名的品类对比（"很多同类产品"）= advice 级（建议具体化或去掉）
```

### 5. 诱导与承诺（依据 FL-005 及平台规则）

```
判据（金融类从严，其他行业按诱导分享平台规则）：
  收益承诺："保本""稳赚""零风险""年化 X% 保证"= 有风险/hard（金融）
  绝对承诺："无效全额退款"之外的绝对效果承诺 = 有风险
  诱导分享："转发领 X""集赞解锁"= 按渠道平台规则（FL-012 待核 → 提示级+排期）
  饥饿营销表述："最后 3 小时"（无真实依据）= advice 级（需核实库存/时间真实性）
```

## 二、行业专项（行业定了才跑；行业未定 = 本节整体 N/A + 报告头声明）

| 行业 | 不可碰项（出现即至少 risk，多数 hard 候选） | 依据 ref |
|---|---|---|
| 医疗/药品/器械 | 大众媒介发处方药广告；疗效保证；患者案例暗示疗效（个案真实也不得用于广告） | FL-002/006 |
| 金融/投资 | 收益承诺；保本表述；以历史业绩暗示未来收益；无资质荐股 | FL-005 |
| 化妆品 | 医疗作用暗示；特殊功效（祛斑美白/防晒/防脱）无注册证宣称 | FL-008 |
| 食品/保健食品 | 普通食品声称保健功能；保健食品宣称治疗功能；"蓝帽子"资质核对 | FL-007 |
| 婴幼儿配方 | 宣称替代母乳；"满足全部营养需要" | FL-006 |
| 教育培训 | 升学/考试/学位的保证性承诺；"包过""保上岸" | FL-009 |
| 房产 | 面积/位置误导表述；"学区房"承诺；未售先售暗示 | 行业条款（事实层待补 FL，当前提示级） |
| 招商加盟 | 收益承诺；"躺赚""零经验月入过万" | FL-005 类推（提示级 + 待补 ref） |

```
行业专项执行纪律：
  行业在 product-marketing.md 里写了 → 跑对应行
  用户说的行业与内容实际展示的行业不一致（如定位 SaaS 但内容在推保健品）
    → 按内容实际行业跑，并在报告头标注"行业字段与实际内容不符，已按实际内容审查"
```

## 三、N/A 原因的标准写法（禁止空 N/A）

```
合格（写明查了什么、为什么不适用）：
  "内容无数字宣称（通篇无百分比/倍数/排名）→ 数据宣称 N/A"
  "非化妆品行业，无功效词汇出现 → 功效宣称 N/A（已全文扫描医疗词汇表）"
不合格（= 视同未查）：
  "N/A"（空）
  "没有"（没说查没查）
  "不涉及"（没写怎么判断的不涉及）
```

## 四、严重度判定规则

```
hard（必须改，改前 blocked）：
  法规明令禁止的表述，且内容明确落入（不是"可能落入"）
  判定前提：依据 ref 状态 = verified 且未过期（未验证的只能到 risk）
risk（需个案判断，给判断依据 + 人确认什么）：
  落入边界（模糊词/个案描述 vs 宣称）或依赖技能没有的信息（资质/出处真实性）
  → 自动进 human_review 候选
advice（最佳实践，不改也可能发）：
  不违反已核实条款，但存在误判风险/平台审核敏感词/表述可更稳
  → 不改也 pass，但列出来让人选
升级规则：同一风险多处出现（≥3 处）→ 升一级（risk→hard 候选，advice→risk）
  理由：系统性问题不是笔误，反映的是撰写流程没把住关
```
