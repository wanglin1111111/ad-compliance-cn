# 中文渠道合规矩阵（Channel Matrix）

> 用途：第 1 步定范围后，按渠道取「渠道专项」检查项。
> 结构分两层：**法规层**（所有渠道共性，依据事实层 FL-001~010）+ **平台规则层**（各渠道差异，依据 FL-011~015，全部短有效期）。
> 平台规则层每条观察都带状态（已核官方文档 / 待核）——**待核的只能用于排期"先核什么"，不能当审查依据**（与事实层状态双轨同构）。

## 一、矩阵总览

| 渠道 | 法规层（共性） | 平台规则层高风险项 | 审核口径观察（状态） |
|---|---|---|---|
| 小红书 | 通用 5 项全适用 | 医疗/健康功效暗示、绝对化用语、营销号判定 | 医疗功效从严（FL-011 待核）；笔记形态下"个人经验"表述也受广告法约束（是否构成广告需个案判断，待核） |
| 公众号/搜一搜 | 通用 5 项全适用 | 诱导分享、外链合规、付费内容标注 | 诱导分享限制（FL-012 待核）；搜一搜收录内容同样受广告法约束（事实常识，条文待核） |
| 抖音 | 通用 5 项全适用 | 素材与落地页一致性、口播功效、医疗类资质 | 素材宣称须在商品页可对应（FL-013 待核）；口播内容 = 广告语，不豁免 |
| 视频号 | 通用 5 项全适用 | 医疗类资质、诱导互动 | 审核口径待核（FL-014 待核）——未核实前渠道专项只能出提示级意见 |
| 百度（推广/百家号） | 通用 5 项全适用 | 搜索广告资质（行业准入）、落地页一致性 | 资质要求待核（FL-015 待核）；医疗/金融类投放资质门槛高（常识级，待核） |
| 私域（朋友圈/微信群） | 通用 5 项全适用 | 诱导分享、刷屏判定、个人号 vs 商家号 | 朋友圈广告化内容仍受广告法约束（是否构成商业广告需个案，待核） |

## 二、渠道专项的检查重点（定渠道后才跑）

```
小红书：
  [ ] 医疗/健康功效暗示（"祛痘""祛斑""改善失眠"在笔记里 = 高风险）
  [ ] 绝对化用语（平台审核对"最/第一"敏感度高）
  [ ] 商品推荐标注（是否构成广告——带购买链接/合作标记的必然构成）
  [ ] 个人经验表述的边界（"我用了三个月白了两个度"——个案描述 vs 功效宣称，
     平台口径待核，出提示级意见并标注）
公众号：
  [ ] 诱导分享话术（"转发 X 人领取""集赞解锁"）
  [ ] 外链指向的落地页内容（外链内容同样在审——只审文章不审外链=漏审）
  [ ] 付费/赞助内容标注
抖音：
  [ ] 素材（画面+口播+字幕）三处一致性——口播说的和落地页写的是不是一回事
  [ ] 功效宣称的口播形式（"说出来"也是广告语）
  [ ] 医疗/健康类目资质（无资质不得投放相关素材）
视频号：
  [ ] 同抖音 + 诱导互动（"转发到 3 个群"）
  [ ] 口径未核实项 → 提示级 + 排期核实
百度：
  [ ] 行业准入资质（医疗/金融/教育投放需资质，无资质 = hard 级风险，
     依据 FL-015 待核 → 当前只能提示级 + 强制 human_review）
  [ ] 搜索词与落地页一致性
私域：
  [ ] 刷屏/重复发送的平台处置风险（平台规则层，非法规层）
  [ ] 朋友圈内容构成商业广告的判定（带产品图+购买方式 = 大概率构成）
  [ ] 微信群内一对一转发广告（同样受广告法约束，不因"私域"豁免）
```

## 三、平台规则层的核实排期（优先级）

```
P0 你实际在投的渠道（product-marketing.md 的渠道策略定）
P1 P0 里审核口径最严的（医疗/金融行业 = 小红书+抖音优先）
P2 其余
最小启动集：1 个主力渠道的官方文档核完（FL-011~015 里对应那一条升 verified）
  ——该渠道的渠道专项才能从"提示级"升级为"正式依据"
核实动作：找到平台官方文档中心对应规则页 → 逐字对照 fact 字段 →
  填 verified_on/source_url/expiry（≤3 个月）→ 更新记录
```

## 四、矩阵的维护纪律

```
[ ] 平台规则层每 3 个月强制重核一轮（expiry 到期自动转 unverified）
[ ] 平台公告/规则更新页每次核实必查（规则变化常无预告）
[ ] 观察列（审核口径观察）与依据列分开写——观察是经验，依据是文档；
    观察可以写进报告"风险提示"，但风险清单的依据字段只能引用依据列的 ref
[ ] 新增渠道：先加一行（全待核）+ 事实层加对应 FL 条目，禁止"凭经验直接写依据"
```
